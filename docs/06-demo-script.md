# Five-minute demo script

## 0:00-0:35 — setup

"ReadyCurrent helps households and field-service businesses stay operational
when the grid is unstable. An outage warning normally starts days of account
research, policy checks, and manual outreach. This experience turns that into
one governed workflow."

## 0:35-1:45 — Seller Home

- Point to pipeline and customer-health context.
- Start the outage-resilience workflow.
- Let the animation explain identification, eligibility, personalization, and
  review preparation.
- State clearly whether segmentation is staged or connected.

## 1:45-2:10 — Business Account

- Show installed backup equipment, coverage gap, service signals, and the
  pre-approved commercial offer.

## 2:10-2:35 — Consumer Profile

- Show how commerce, service, and engagement create one household view.

## 2:35-3:35 — Beacon

- Ask Beacon to prepare for the business account.
- Toggle one simulated application connector and repeat a relevant question.
- If using live mode, identify it truthfully; otherwise call it deterministic.

## 3:35-4:45 — Slack and completion

- Open the List.
- Edit one draft and approve intended rows.
- React with the white check mark.
- Show processing acknowledgment, Salesforce activity, and completion.

## 4:45-5:00 — close

"The differentiation is not one AI answer. It is unified context, a custom
experience, model choice, human control, and observable completion on one
governed platform."
