# Story and discovery

## The business moment

ReadyCurrent sells backup-power hardware and monitoring plans. A regional grid
operator publishes an elevated outage-risk alert. Sellers normally spend days
finding customers whose hardware or plan coverage may be insufficient,
confirming fictional rebate eligibility, researching each relationship, and
drafting outreach.

Beacon compresses that work into a governed sequence:

1. Identify lapsed or under-covered households and businesses.
2. Determine which records meet the fictional Resilience Credit policy.
3. Prepare individualized drafts using profile and service context.
4. Ask a seller to review and approve.
5. Process only approved rows and write the result back.

## Discovery worksheet

Before adapting the blueprint, answer:

- What external event creates urgency?
- Which customer groups are affected?
- What does a seller or service rep do manually today?
- Which policy or eligibility decision blocks action?
- Which data source answers each question?
- What can an agent prepare safely?
- What requires human authorization?
- Which record proves completion?
- What metric makes the workflow worth changing?

If a page or feature does not help answer one of these questions, remove it.
